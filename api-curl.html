LedgerOne API: curl commands

Copy any command with its Copy button. Start the app first with ./start.sh, then run the commands in order: login first, then use the token from step 2 in the Authorization header.

Commands below update to use this base URL.

1. Send OTP

POST /api/auth/otp. Sends an OTP to the mobile number. Any 10-digit number is accepted.

Request
Response 200
{
  "message": "OTP sent",
  "expiresInSeconds": 300,
  "mockOtp": "123456"
}

2. Verify OTP (login)

POST /api/auth/verify. Use 123456 as the OTP. Save the returned token.

Request
Response 200
{
  "token": "mock-session-jwt-token-active"
}

3. Get account

GET /api/account. Requires the bearer token.

Request
Response 200
{
  "account": {
    "name": "Asha Rao",
    "phone": "9876543210",
    "email": "asha.rao@ledgerone.io",
    "accountName": "Savings Account",
    "accountNumber": "920010048210943",
    "ifsc": "HDFC0000240",
    "balanceMinor": 24567890,
    "currency": "INR"
  }
}

balanceMinor is in paise. 24567890 is ₹2,45,678.90.

4. Get transactions

GET /api/transactions. Requires the bearer token.

Request
Response 200 (shortened)
{
  "transactions": [
    {
      "id": "tx-001",
      "title": "Monthly Salary Credit",
      "subtitle": "TechCorp India · NEFT",
      "amountMinor": 21500000,
      "direction": "CREDIT",
      "timestamp": 1793795327570
    }
    // ... 4 more transactions
  ]
}

5. Logout

POST /api/auth/logout. Requires the bearer token. The mock does not revoke the token, so it still works in curl after logout.

Request
Response 200
{
  "ok": true
}
